| Platform | Installer |

## Installation

### Windows

1. Download the `.exe` or `.msi` installer from the [latest release](https://github.com/dragonscale-ai/rustic-studio/releases/latest).
2. Run the installer and follow the on-screen instructions.
3. Launch **Rustic Studio** from the Start Menu or Desktop shortcut.

### macOS

1. Download the `.dmg` file from the [latest release](https://github.com/dragonscale-ai/rustic-studio/releases/latest).
2. Open the `.dmg` file and drag **Rustic Studio** to your Applications folder.
3. Launch **Rustic Studio** from your Applications folder or Spotlight.

> **Note:** On macOS, you may need to allow the app in **System Preferences → Privacy & Security** the first time you open it.

### Linux

#### AppImage

1. Download the `.AppImage` file from the [latest release](https://github.com/dragonscale-ai/rustic-studio/releases/latest).
2. Make it executable: `chmod +x RusticStudio-*.AppImage`
3. Run it: `./RusticStudio-*.AppImage`

#### Debian/Ubuntu

1. Download the `.deb` package from the [latest release](https://github.com/dragonscale-ai/rustic-studio/releases/latest).
2. Install it: `sudo dpkg -i rustic-studio_*.deb`
